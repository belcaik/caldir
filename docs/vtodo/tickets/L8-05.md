## Notes for the implementer

- **Trap — running the TZ loop in parallel.** `rust-toolchain.toml` pins `1.97.0`; two concurrent cargo
  invocations race rustup and corrupt the toolchain. Install serially first
  (`rustup toolchain install 1.97.0 --profile minimal -c clippy,rustfmt`) and loop sequentially.
- **Trap — accepting a "trivial" test edit.** R104 calls any required edit to an existing event test a
  design failure. The most likely offender is a `use` line or an accessor rename that crept beyond `L2-06`'s
  five sanctioned files. Check the *assertion lines*, not the diff summary.
- **Trap — `fail-fast`.** Use `--no-fail-fast` so one zone's failure does not hide the others'.
- **Trap — counting.** 686 is the pre-feature baseline across nine targets (`testing.md` §1 has the table).
  A count that dropped means a test was deleted or `#[ignore]`d — investigate, never accept.
- Deliver the C1–C13 table and the `T-1`..`T-59` checklist as the ticket's output. That table is the Stage 9
  citation handle.
