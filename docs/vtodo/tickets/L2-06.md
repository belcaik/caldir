# L2-06 — contract: the loader admits tasks ⚑ *the green moment*

**Layer:** L2 · **PR-2** · **Depends on:** `L2-03`, `L2-04`, `L2-05` (all three merged)

> **This is the narrowest node in the graph and its highest-risk ticket.** Every downstream layer
> (L3, L4, L5, L6, L7) transits it. INDEX §3: *"schedule it early and give it your strongest
> agent."* Read the whole ticket before writing a line.

## Responsibility

Flip the contract. Delete the temporary accessors `L2-02` introduced; retype
`Event::from_ics_str → Vec<Result<CalendarItem, EventError>>` and
`Event::from_single_ics_str → CalendarItem`; make `CalendarEvent::load` return a task for a VTODO
file; make `CalendarEvent::event()` a narrowing `Option<&Event>`.

Three of the five immutable Stage-2 RED tests go green here. Two more go green at `L2-07`.

## Requirements satisfied

- **R5 (load half)** — "A file containing exactly one VTODO MUST load, MUST NOT error, and MUST
  NOT prevent any sibling file, sibling calendar, or CLI aggregation from loading."
- **R32** — "A local `.ics` file MUST contain **exactly one supported component** (`VEVENT` or
  `VTODO`)."
- **R19 (INVIOLABLE, must not regress)** — "An unsupported data-bearing component (`VJOURNAL`,
  `VFREEBUSY`, unknown, `X-`) MUST produce a **hard error naming the component** — never a silent
  skip, never an empty vector. A silent drop feeds the delete path (R48, §15 C7/C10)."
  The flip changes what the loader *returns*; it must not change what it *rejects*. **There is no
  `_ => skip` arm.** ADR-01 step 5's `_ => skip` is STRUCK by ADJUDICATION B-3.
