# L7-05 — `doctor` re-lock after component skipping

## Responsibility

Re-assert `T-43` against the **post-abstraction** item-backed loader: a syntactically broken **VEVENT** must
still surface as `DoctorWarning::UnreadableEvents`. Graceful degradation (PR-1) plus component skipping
(L2-*) must not start silently swallowing malformed files. No production behaviour change is expected —
this ticket exists to prove one, and to fix `doctor` if it regressed.

## Notes for the implementer

- **Trap — "empty" is not "malformed".** R75 requires the vocabulary to distinguish *no supported component*
  ("no VEVENT or VTODO in `{path}` (found: `{names}`)") from *too many*. A VTODO-only file and an empty
  VCALENDAR both reported `found: 0` before this feature; after it they must not. If your malformed fixture
  accidentally parses to "empty", the test proves nothing.
- **Trap — the skip path.** After `L0-01`, a bad file can be *skipped and reported* rather than aborting the
  listing. `doctor` must still turn that report into `UnreadableEvents`; a skipped file that produces no
  warning is exactly the silent swallow R77 forbids.
- If this ticket finds `doctor` genuinely regressed, that is a real finding: fix it here and note it, since
  `L8-05` (the acceptance gate) will otherwise catch it much later and much more expensively.
- Toolchain `1.97.0`; clippy `-D warnings`; CLI tests use `indoc`; never run two cargo commands in parallel.
