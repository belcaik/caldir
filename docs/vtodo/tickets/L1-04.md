# L1-04: Todo ICS serialization, incl. the hand-rolled VALARM splice

**PR-2.**

## Responsibility
`Todo` → a single-component `VCALENDAR` document, CRLF throughout, `DTSTAMP` re-stamped at write
time (never a field), and `VALARM` blocks spliced onto the literal `"END:VTODO\r\n"` — mirroring the
event splice. **Never** call `ends()` or `all_day()`; **never** emit `DTEND` or `DURATION`.

## Requirements satisfied
- **R8** — *"A task MUST NOT carry `DTEND` or `DURATION`. RFC 5545 §3.6.2 forbids `DTEND` in a VTODO, and `icalendar` 0.17.10 emits one via the leaked `EventLike::ends()` (verified on pinned `=0.17.10`, GRILL C-3). Emitting it is a defect, not merely out of scope."*
- **R24** — *"A task's `VALARM` MUST be emitted through caldir's hand-rolled block spliced on the literal `"END:VTODO\r\n"`, mirroring the event splice (`event.rs:249`), and MUST NOT use the crate's alarm builder… the crate path regenerates a fresh `Uuid::new_v4()` and `Utc::now()` on **every** serialize, so two generations compare unequal and every sync pushes forever; the splice path is byte-stable across three generations."*
- **R25** — *"`DTSTAMP` MUST NOT be a field on the task type: dropped at parse, re-stamped by serialization, exactly as for events. Not-a-field beats ignored-field…"*
- **R26** — *"Serializing a task MUST NOT emit `DTEND` or `DURATION`; a test MUST assert `DTEND`'s absence (T-11)."*
- **R27** — *"Serialization MUST emit exactly one supported component per `VCALENDAR` document."*
- **R28** — *"Output MUST use CRLF throughout (the crate's `write_crlf!` guarantees it)."*
- **R29** (tolerate side) — *"Whether caldir emits `VTIMEZONE` for a zoned `DUE`/`DTSTART` is **open** (Q-3). Whichever is chosen, the system MUST tolerate Radicale adding one, and no gate may compare raw bytes across the wire (R30)."*

## RED tests
- **ADD** `todo::to_icalendar::tests::serializing_a_task_never_emits_dtend` (**T-11**, R8/R26) in
  `caldir-core/src/todo/to_icalendar.rs`. Asserts the serialized document contains no `DTEND` and no
  `DURATION` line — including for a task that has both `DTSTART` and `DUE`. Right proof: the crate's
  leaked `EventLike::ends()` emits `DTEND` on a VTODO on pinned `=0.17.10`, and the resulting file is
  RFC-invalid; the only defence is an explicit absence assertion.
- **ADD** `todo::tests::valarm_is_byte_stable_across_three_generations` (**T-12**, R24) in
  `caldir-core/src/todo.rs`. Serializes a task carrying a reminder three times and asserts the
  `VALARM` block is byte-identical across all three. Right proof: the crate's alarm builder mints a
  fresh `Uuid::new_v4()` per serialize, so generation 2 differs from generation 1 — which makes every
  sync push forever. Three generations, not two, because the failure is per-call.
- **ADD** `todo::tests::two_serializations_with_different_wall_clocks_compare_equal` (**T-19**, R25)
  in `caldir-core/src/todo.rs`. Serializes, re-parses, and asserts the two parsed `Todo`s are `==`
  despite differing `DTSTAMP` lines. Right proof: it is the exact churn mechanism R25 exists to
  prevent, asserted at the domain level rather than on bytes (R30's rule).

## Acceptance criteria
1. `Todo::to_ics_string()` (or the equivalent named to match `Event`'s) produces a `VCALENDAR` with
   `VERSION` and `PRODID` and exactly one `VTODO` component. (R27)
2. No `DTEND` and no `DURATION` appears in any output; `ends()` / `all_day()` are never called.
   (R8, R26, T-11)
3. `DTSTAMP` is emitted, freshly stamped, and is not a struct field. (R25)
4. `VALARM`s are emitted via the hand-rolled splice on `"END:VTODO\r\n"`; the crate's alarm builder is
   not used. (R24, T-12)
5. Every line ends `\r\n`. (R28)
6. Whatever the Q-3 decision turns out to be, nothing here *depends* on the server not adding a
   `VTIMEZONE`. (R29)
7. `just check` green; T-11/T-12/T-19 pass; `just test` 686 baseline unmodified. (R104)

## Non-goals
- **Do not decide Q-3** (whether caldir emits `VTIMEZONE` for a zoned `DUE`/`DTSTART`). `L5-05`
  decides and records it against the live server.
- **Do not** write a raw-bytes round-trip gate (`serialize == original input`). R30 forbids that
  class of comparison for acceptance; here it would also fail on the re-stamped `DTSTAMP`. Compare
  parsed-domain `==`.
- **Do not** touch `caldir-core/src/event/to_icalendar.rs` or `event.rs`'s splice — R2/C2 are
  INVIOLABLE. Mirror the pattern, do not generify it.
- No `CATEGORIES` emitter (R88 — a correct one needs hand-rolling and is a follow-up ADR for both
  kinds), no `RELATED-TO` (R87).
- No file writing, no filename choice (`L1-07`), no `CalendarItem` (`L2-01`), no RPC codec (`L4-01`).

## Notes for the implementer
- **The `EventLike` trap.** `icalendar::Todo` implements `EventLike`, so `ends()` is in scope and
  compiles. Calling it emits `DTEND` on a VTODO — verified on pinned `=0.17.10`. Do not import
  `EventLike` into this module unless you need it, and if you do, keep a grep-able comment saying
  `ends()`/`all_day()` are forbidden here.
- The splice is a literal `replacen("END:VTODO\r\n", …, 1)` — note the CRLF **inside the literal**
  and the `1`. `event.rs:249` is the model; copying it and changing `VEVENT`→`VTODO` is the intent.
- Early-return when there are no reminders, as `event.rs:242-244` does, so a task without alarms
  costs nothing.
- **Probe hygiene (R108)** if you re-verify any crate behaviour: pin `icalendar = "=0.17.10"`, print
  the resolved version, and echo the exact input bytes sent. The original VALARM probe in this effort
  silently resolved **0.17.13** behind a caret requirement and had to be re-run (ADJUDICATION C-3).
  *A probe that returns the answer you expected is not evidence until you have inspected the input it
  actually sent.*
- T-19's fixture needs two serializations whose `DTSTAMP` genuinely differ. Do not sleep; construct
  the second document by editing the `DTSTAMP` line of the first, or serialize twice and assert on the
  parsed values rather than on wall-clock timing.
- Conventions: inline `#[cfg(test)] mod tests`, no fixture files,
  `use pretty_assertions::assert_eq;`. CI: `-D warnings` on `just check`; TZ matrix on `just test`.
